# ts-typegen-macros

Derive macro implementation for [`ts-typegen`](https://crates.io/crates/ts-typegen),
which generates TypeScript types from Rust structs and enums at build time.

This crate is an implementation detail. Depend on `ts-typegen` instead — it
re-exports the `Ts` derive, and the version pair is expected to match.

See the [project README](https://github.com/Andrew-McCall/typescript-typegen-rs)
for documentation.
